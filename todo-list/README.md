# Мой день — список задач

Адаптивный To-Do List на HTML, CSS и JavaScript. Задачи хранятся локально в браузере и не отправляются на сервер.

## Возможности

- Добавление задач по кнопке или Enter.
- Отметка выполнения и возврат задачи в работу.
- Удаление задач и очистка выполненных.
- Фильтры: все, в работе, готово.
- Сохранение списка после обновления страницы через `localStorage`.
- Адаптация под мобильные устройства и доступные подписи для скринридеров.

## Запуск

Откройте `index.html` в браузере или разместите файлы на статическом хостинге.

## Технологии и AI-инструмент

- HTML, CSS, Vanilla JavaScript.
- При создании проекта использован ChatGPT (OpenAI).
